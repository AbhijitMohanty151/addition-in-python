# Addition in Python

## add(a, b)
### add(a, b, c=0)

This function returns the sum of three numbers. The third number is optional and defaults to 0 if not provided.

### Parameters

*   `a` (int or float): The first number to be added.
*   `b` (int or float): The second number to be added.
*   `c` (int or float, optional): The third number to be added. Defaults to 0.

### Returns

The sum of the three numbers.

### Example

```python
result = add(1, 2)
print(result)  # Output: 3

result = add(1, 2, 3)
print(result)  # Output: 6
```

Note: The `add` function is deprecated. Please use the new implementation with three parameters instead.

## `multiply`

The `multiply` function takes two numeric arguments, `a` and `b`, and returns their product.

#### Parameters

*   `a`: The first number to multiply.
*   `b`: The second number to multiply.

#### Return Value

The result of multiplying `a` by `b`.

#### Exceptions

None. This function does not raise any exceptions.

#### Usage Example

```python
result = multiply(4, 5)
print(result)  # Output: 20
```

## `subtract`

The `subtract` method takes two parameters, `a` and `c`, and returns their difference.

#### Parameters

*   `self`: The instance of the class.
*   `a`: The first number to subtract from.
*   `c`: The number to subtract.

#### Return Value

Returns the result of the subtraction operation (`a - c`).

#### Exceptions

None, as this method does not raise any exceptions.

#### Usage Example

```python
subtract_result = my_instance.subtract(10, 5)
print(subtract_result)  # Output: 5
```
